### 🧑‍💻 About me

I'm a **Computer Systems** undergraduate at ORT University Uruguay and an **Operations Specialist** at an energy distribution company.

That intersection shapes how I work: I operate critical infrastructure by day and build cloud architectures and data pipelines the rest of the time. I understand a production incident from both sides — the system's and the business depending on it.

- ☁️ Currently focused on **AWS** and **Infrastructure as Code** with Terraform
- 📊 Designing and building end-to-end **data pipelines**
- 🔌 Backend and **distributed systems** in .NET
- 🏠 Running my own Raspberry Pi homelab, because the best way to understand infrastructure is to break it

### 🚀 Projects

**🧬 BioTrack Personal** &nbsp;·&nbsp; ![Private](https://img.shields.io/badge/repo-private-6E7681?style=flat-square)
A local system that consolidates years of lab results scattered across PDFs into a queryable database with longitudinal tracking per marker. Gmail ingestion, coordinate-based PDF extraction and fuzzy normalization of analyte names.
`Python` `pdfplumber` `pandas` `SQLite` `Google API` `pre-commit`

**☁️ AWS Infrastructure with Terraform**
A multi-tier AWS architecture provisioned entirely as code: VPC with public and private subnets, ALB with Auto Scaling, isolated RDS and centralized observability. Includes a custom CloudWatch Logs module with its agent configured through SSM Parameter Store.
`Terraform` `AWS` `EC2` `VPC` `S3` `Lambda` `RDS` `CloudFront` `IAM`

**📊 Big Data Pipeline — INUMET** &nbsp;·&nbsp; [![Repo](https://img.shields.io/badge/view_repo-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/Frankitop/HSBD_N7A_269387_252446)
A complete pipeline over Uruguay's open weather data: NiFi ingestion into zoned HDFS, Spark processing, a dimensional model in Hive and Superset dashboards.
`Apache NiFi` `Spark` `HDFS` `Hive` `Superset` `Parquet` `Jupyter`

**🔌 Distributed System in .NET**
A class management system built from five decoupled modules, spanning the full communication spectrum: from raw TCP sockets with a custom framing protocol up to gRPC, async messaging and real-time chat. Fully containerized.
`C#` `.NET 8` `gRPC` `Protobuf` `RabbitMQ` `WebSockets` `Docker Compose` `SQL Server`

**🏠 Raspberry Pi Homelab**
Self-hosted home infrastructure: home automation, VPN and filtered DNS behind a reverse proxy with TLS auto-renewed via DNS-01.
`Docker Compose` `Nginx Proxy Manager` `WireGuard` `Home Assistant` `Pi-hole` `Let's Encrypt`

**📚 AI-Assisted Study Vault** &nbsp;·&nbsp; ![Private](https://img.shields.io/badge/repo-private-6E7681?style=flat-square)
A version-controlled vault where class material becomes interlinked notes through an agentic workflow with Claude Code: custom skills, declared conventions and a Python auditor that flags broken wikilinks and orphan notes.
`Python` `Obsidian` `Claude Code` `Git hooks` `Bash`

**🎯 Cupo Recuperado** &nbsp;·&nbsp; [![Demo](https://img.shields.io/badge/view_demo-000000?style=flat-square&logo=vercel&logoColor=white)](https://cupo-recuperado-app.vercel.app)
A working prototype for reclaiming cancelled clinic appointments: nine screens, two roles, and slot availability resolved by a single pure domain function.
`React 18` `Vite` `React Router` `Context API` `Vercel`
